# Glossary - The Great Battle Gaiden 2: Matsuri da Wasshoi

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.
The check tool enforces the tables: a JP term in the Japanese requires its EN form in the English; Avoid = banned.

## Rulings (user, 2026-10-10)
- Honorifics: kept (-san, -sama, -kun). Name order: Japanese.
- Romanisation: official English names (Ultraman, Kamen Rider, Gundam, Compati Hero series) first, else Hepburn
  without macrons. Research: docs/research-names.md.
- Credits: English.
- Abbreviations: none. Full names and terms; prefer engine work / extra pages over shortening.

## Style rules
- Punctuation: 「」 -> "...", ”...” -> "...", ・・・ -> ..., ！？ -> !?
- Font has only: A-Z a-z 0-9 space ! ? ( ) : / " . ' , -
